# Flow Project — Start Here

Goal: prove or kill whether the newsletter's proprietary **Systematic Flow Risk** signal
has real, usable predictive edge (vs. just keeping the reproducible gamma/vol signals).

## How to start
1. Open this folder in a **fresh** chat session (clean context).
2. Read `_msr_flow_project_brief.md` — it has the full background, the promising-but-unproven
   finding, the caveats to break, and a **paste-ready kickoff prompt** at the bottom.
3. Paste that kickoff prompt to begin.

## Files here
- `_msr_flow_project_brief.md` — the brief + kickoff prompt (READ FIRST)
- `_msr_flow_research.csv` — 281 daily rows: regime labels + context + precomputed forward returns
- `_msr_methodology_spec.md` — full feature definitions & reproducibility tiers (reference)
- `msr.db` — the full database, if deeper joins are needed

These are COPIES; the originals live one level up in the Tier 1 Alpha folder.
