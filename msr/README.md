# msr

Turns the daily Market Situation Report (MSR) newsletter PDFs into feature data
(`msr.db` + CSVs) that the backtester merges in as a gamma/vol overlay. Pure data
prep — no strategy logic, no live connections.

Comes from `Tier 1 Alpha` (keeps its PDF archive + the closed Flow Project research).

> Folder name up for review: `msr` is jargon. Say the word if you'd rather call it
> `newsletter` or `reports`.
